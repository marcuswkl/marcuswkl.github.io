# marcuswkl.github.io

Minimal static personal site built with a modern frontend stack and deployed to GitHub Pages.

Currently not in use and redirects to my LinkedIn profile.

## Tech Stack

- TypeScript
- Next.js (static export / SSG)
- React Compiler
- Tailwind CSS
- Biome (linter)
- Bun (package manager)

## Deployment

- Static export (out/)
- Deployed via GitHub Actions to GitHub Pages
